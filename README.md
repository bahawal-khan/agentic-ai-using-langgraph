## 📌 About

A hands-on **LangGraph learning and experimentation repository** focused on understanding how modern LLM applications are designed using **stateful workflows, memory, tools, and retrieval**.

This repository contains focused practice implementations that build the foundation for developing complete **Agentic AI systems**.

---

## 🧩 What I Practiced

### 🔀 LangGraph Workflows
- Sequential & parallel workflows
- Conditional routing and decision-making
- Prompt chaining
- State management
- Subgraphs and shared/different state
- Iterative workflows

### 🧠 Memory
- Conversational state
- Short-Term Memory (STM)
- Summarization-based memory
- Long-Term Memory (LTM)

### 🛠️ Tools & Tool Calling
- LLM-powered tool usage
- Tool calling workflows
- Connecting tools with LangGraph nodes
- Building workflows where the LLM can decide **when a tool is needed**

### 📚 RAG & Advanced Retrieval
- Retrieval-Augmented Generation (RAG)
- Corrective RAG (CRAG)
- Self-RAG
- Retrieval evaluation and corrective decision-making
- Combining retrieval with LangGraph workflows

### 🤖 LLM-Based Workflows
- Sentiment analysis
- Essay analysis
- Content generation
- Structured multi-step LLM workflows
